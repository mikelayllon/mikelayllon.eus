# mikelayllon.eus

Mikel Ayllonen webgune pertsonala. [Astro](https://astro.build)-rekin egina, [Netlify](https://netlify.com)-n argitaratua eta [Pages CMS](https://pagescms.org) panelarekin editatua.

## Edukiak

Testu guztiak panelean edita daitezke (`.pages.yml`):

- `src/content/koadernoa/` — Koadernoko sarrerak (euskaraz)
- `src/content/lanak/` — Lanak, hiru hizkuntzatan
- `src/content/orriak/` — Hasiera, Zerbitzuak, Ikerketa, Niri buruz eta ezarpenak
- `public/irudiak/` — Irudiak eta audioak

Hizkuntzak: euskara (`/`), gaztelania (`/es/`), ingelesa (`/en/`). Koadernoa euskaraz bakarrik.

## Lokalean

```sh
npm install
npm run dev
```
